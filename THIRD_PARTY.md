# Third-party components

- Minecraft and Fabric Loader/API/Loom: build and runtime dependencies, not vendored.
- ViaFabricPlus 5.1.1 API: optional compile dependency under GPL-3.0-or-later. Users install ViaFabricPlus separately for translation. RiftDLC does not copy its source.
- ViaVersion: transitively supplied by ViaFabricPlus API and runtime mod.
- Fabric example mod (CC0): consulted for 26.3 build conventions. The Gradle wrapper files are from the same toolchain; no Meteor source was copied.
- Meteor Client (GPL-3.0): studied as reference only. No source or assets copied.
